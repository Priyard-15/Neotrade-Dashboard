15.Write a program to check whether a number is a palindrome.

Code:
n = int(input())
original = n
reverse = 0
while n > 0:
  digit = n % 10
  reverse = reverse * 10 + digit
  n = n // 10
  if original == reverse:
    print("Palindrome")
  else:
    print("Not Palindrome")

Input:
121

Output:
Palindrome

Time Taken: 90 sec

19.Write a program to find the largest element in a list.

Code:
n = int(input())
arr = list(map(int, input().split()))
largest = arr[0]
for i in range(1, n):
  if arr[i] > largest:
    largest = arr[i]
    print(largest)

Input:
